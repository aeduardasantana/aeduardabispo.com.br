# aeduardabispo.com.br

Site oficial de Eduarda Bispo.

## Objetivo

Centralizar a marca pessoal Eduarda Bispo e organizar, em um único ponto, suas principais áreas de atuação, projetos, conteúdos e canais oficiais.

## Estrutura

- Negócios & Gestão
- Educação
- Libras & Surdez
- Saúde & Desenvolvimento
- Tecnologia
- Conteúdo & Pesquisa
- Projetos
- Trajetória
- Publicações
- Canais oficiais
- Contato

## Tecnologia

Site estático em HTML, CSS e JavaScript, sem dependência do Lovable.

## Publicação

O repositório contém arquivo `CNAME` para o domínio:

`aeduardabispo.com.br`

A troca efetiva do domínio exige configurar a hospedagem escolhida e apontar o DNS para ela.

## Arquivos principais

- `index.html` — conteúdo e estrutura
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação mobile
- `robots.txt` e `sitemap.xml` — SEO
- `CNAME` — domínio personalizado
